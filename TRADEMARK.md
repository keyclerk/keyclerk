# Name use

"KeyClerk" names this project. The steward named in [NOTICE](NOTICE) holds the name; it is not a registered trademark.

- You may use the name to refer to the project, and to say a product works with KeyClerk or is built on it.
- A modified version must not be called KeyClerk or presented as an official release without a clear statement of
  what was changed.
- The mark in `brand/` may be used, unmodified, to point to this project.
- An edge implementation may say it "conforms to the KeyClerk edge protocol X.Y" only if it passes that version's
  conformance set (github.com/keyclerk/edge-protocol).

Questions: open an issue with the "need" form.
